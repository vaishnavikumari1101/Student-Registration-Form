# Student Registration Form

A simple and responsive Student Registration Form built using HTML and CSS.

## Features

- Student Full Name
- Email Address
- Phone Number
- Date of Birth
- Gender Selection
- Course Selection
- Address Field
- Clean and Simple UI

## Technologies Used

HTML5
CSS3

## Project Structure

Student-Registration-Form/
│
├── index.html
├── style.css
└── README.md

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
